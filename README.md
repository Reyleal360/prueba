# Material de Apoyo: Prueba Tcnica

Este repositorio contiene todo lo necesario para afrontar una prueba tcnica de Full Stack.

## Estructura del Repositorio
- **/sql**: Modelo de base de datos e-commerce, consultas eficientes y explicacin.
- **/frontend**: Aplicacin React moderna que consume una API real (`dummyjson.com`).
- **/algorithms**: Implementacin optimizada de "Two Sum" con anlisis de complejidad.

## Cmo usar este material
1. **Frontend**:
   - `cd frontend`
   - `npm install`
   - `npm run dev`
2. **SQL**: Revisa `schema.sql` para el diseo y `query.sql` para bsquedas avanzadas.
3. **Algoritmos**: Ejecuta `node algorithms/two_sum.js` para ver la lgica en accin.

## Consejos para la Prueba
- **Claridad**: Escribe cdigo limpio y comenta las partes complejas.
- **Manejo de Errores**: Siempre implementa `try/catch` y estados de carga en el frontend.
- **Diseo**: Usa variables CSS y layouts responsivos.
- **Algoritmia**: Explica tu razonamiento antes de codificar.
